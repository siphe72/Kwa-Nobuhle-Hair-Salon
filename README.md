#  Kwa Nobuhle Hair Salon Website

An elegant, multifunctional web application developed for Kwa Nobuhle Hair Salon. The website provides a luxury digital showcase for the salon, featuring an interactive service menu, weekly availability scheduling, an online booking system, and a modern visual presentation.



##  Features

* **Home Page (`index.html`):** Welcoming landing page introducing the salon's mission, high-resolution visual banner, and quick navigation.
* **Services & Pricing (`services.html`):** Itemized list of hair care services, treatments, and styling options complete with duration and pricing.
* **Online Booking & Schedule (`booking.html`):** Display of weekly operating hours alongside an interactive appointment booking form with client input validation.
* **Responsive Design:** Fully optimized layout for desktop, tablet, and mobile devices using clean HTML5 and CSS3 styling.



##  Built With

* **HTML5:** Semantic structure and page architecture.
* **CSS3:** Custom styling, responsive layouts, color palette, and typography.
* **JavaScript (ES6):** Dynamic form processing and input validation.
* **GitHub Pages:** Web hosting and continuous deployment.
